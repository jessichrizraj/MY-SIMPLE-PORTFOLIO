# MY-SIMPLE-PORTFOLIO
# Personal Portfolio Website 🌐

## 📌 About the Project

This is a simple and responsive Personal Portfolio Website developed using **HTML5 and Basic CSS3**. The main purpose of this project is to showcase my personal information, skills, interests, and contact details through a clean and attractive website.

This project is one of my beginner-level web development projects, where I practiced building web pages and styling them using HTML and CSS.

## ✨ Features

- Simple and clean user interface.
- Personal introduction section.
- Home page with basic personal information.
- Contact page to display contact details.
- Basic CSS styling for an attractive appearance.
- Easy-to-use navigation between pages.
- Beginner-friendly website structure.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the website.
- **CSS3** – Used to style and design the web pages.

## 📂 Pages Included

- **Home Page:** Introduces me and provides basic information about myself.
- **Contact Page:** Provides contact information and ways to get in touch with me.

## 🎯 Learning Outcomes

Through this project, I gained practical experience in:

- Creating website layouts using HTML.
- Applying CSS styles to HTML elements.
- Understanding basic webpage structure.
- Working with links and navigation.
- Organizing files and project folders.
- Improving my frontend development skills.
